Place the Kaggle version-1 `used_cars_data.csv` in `data/raw/`, or run `cars download`.

The source CSV is 9,980,208,148 bytes. It is intentionally not tracked. `cars demo` creates a separate synthetic dataset in `data/demo/`; it is not a subset of Kaggle data.

Source and usage notice: https://www.kaggle.com/datasets/ananaymital/us-used-cars-dataset
